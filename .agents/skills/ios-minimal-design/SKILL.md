# iOS Minimalist Design & Anti-AI-Slop System

A strict design system and production guide for building high-end, minimalist, modern mobile interfaces with the elegance, restraint, and tactile precision of Apple iOS.

---

## 1. The Core Philosophy: Purging "AI Slop"

"AI Slop" in UI design refers to excessive, generic, low-effort aesthetic tropes commonly generated by AI models when asked to create "futuristic", "cool", or "high-tech" designs. 

### AI Slop vs. Modern Apple HIG

| Dimension | ❌ AI Slop (Avoid at all costs) |  Apple Minimalist HIG (Mandatory) |
| :--- | :--- | :--- |
| **Backdrop** | Muddy gray-blue gradients, noisy patterns, glowing grid lines | True OLED Black (`#000000`) with discrete obsidian surface layers |
| **Color Palette** | Multi-colored neon overload (cyan + purple + magenta everywhere) | Monochromatic foundation with **one** intentional, high-contrast accent tint |
| **Loaders & Status** | Fake 0%-100% progress bars, pseudo-hacky boot sequences | Instantaneous transitions, subtle skeleton pulses, or zero decorative waiting |
| **Card Borders** | 2px radioactive glowing outlines, nested glowing boxes | Ultra-refined hairline borders (`1px` or `hairlineWidth` with `rgba(255,255,255,0.08-0.12)`) |
| **Typography** | Uppercase bracketed techno-babble (`[SYSTEM READY]`, `[CORE 100%]`) | SF Pro typographic hierarchy: clear, human, legible, natural sentence case |
| **Iconography** | Clipart shields, bulky 3D badges with multi-layered glowing rings | Clean vector geometry, uniform stroke weights (2.5px - 3.2px), Apple SF Symbols aesthetic |
| **Layout** | Crammed badges, stacked pills, buttons competing for attention | Generous negative space, clear visual hierarchy, content-first deference |

## 2. iOS Design Tokens & Standards

### A. Squircle Geometry (Continuous Corner Curvature)
iOS uses superellipse "squircle" curves rather than plain sharp chamfers or circular pills:

- **App Icons / Centered Emblems (72–88px)**: `borderRadius: 20` to `24`
- **Main Surface Cards / Modules**: `borderRadius: 20` to `24`
- **Secondary / Nested Cards**: `borderRadius: 14` to `16`
- **Buttons & Text Inputs**: `borderRadius: 12` to `14`
- **Status Pills / Small Badges**: `borderRadius: 8` to `10`
- **Micro Progress Trackers**: `borderRadius: 3` to `4`

### B. Elevation & Surfaces (Dark Mode Hierarchy)
Never use harsh gray backgrounds. Build depth through calibrated dark obsidian surfaces:

```typescript
export const IOS_SURFACES = {
  canvas: '#000000',       // Base OLED pitch black
  cardPrimary: '#121217',  // Top-level elevated container
  cardSecondary: '#1C1C24',// Nested sub-block / selection pill
  surfaceHover: '#262633', // Active or pressed surface
  borderSubtle: 'rgba(255, 255, 255, 0.08)',
  borderNormal: 'rgba(255, 255, 255, 0.12)',
  borderActive: 'rgba(255, 255, 255, 0.24)',
};
```

### C. Apple-Grade Drop Shadows
Avoid muddy or radioactive colored glows. Use soft, deep, high-blur shadows with low opacity:

```typescript
export const IOS_SHADOWS = {
  card: {
    shadowColor: '#000000',
    shadowOffset: { width: 0, height: 8 },
    shadowOpacity: 0.4,
    shadowRadius: 18,
    elevation: 8,
  },
  modal: {
    shadowColor: '#000000',
    shadowOffset: { width: 0, height: 16 },
    shadowOpacity: 0.6,
    shadowRadius: 28,
    elevation: 16,
  },
};
```

## 3. Atmospheric Visual Depth (Subtle Ambient Motion & Falloff Gradients)

When adding visual atmosphere (e.g., floating dumbbells, particles, geometric lines):
1. **Low Contrast Ambient Elements**: Keep opacity between `0.08` and `0.18`. The background must never compete with foreground content.
2. **Gradient Dissolve to Black**: The upper half contains the ambient floating elements, then an SVG `<LinearGradient>` smoothly transitions down into 100% solid OLED Black (`#000000`).
3. **Physics-Driven Loops**: Use `Animated.loop` with `Easing.inOut(Easing.sin)` and `useNativeDriver: true` for 60/120fps stutter-free rendering.
4. **React Compiler / React 19 Safety**: Always initialize persistent animated values using `useState(() => new Animated.Value(...))` to prevent React 19 ref access errors during render.


## 5. The 5-Point Anti-AI-Slop Review Checklist

Before finalizing any screen or UI component, verify against this checklist:

1. **Zero Fake Waiting**: Are there any fake loading spinners, percentage counters (0%-100%), or mock boot logs? If yes, eliminate them immediately.
2. **Color Restraint**: Are there more than two vivid accent colors on screen? Reduce to a single signature accent (e.g. Amber `#FFA620`) backed by pure white and neutral grays.
3. **No Techno-Jargon Clutter**: Are there bracketed labels like `[INITIALIZING...]` or decorative code snippets? Replace with clean, natural language or remove entirely.
4. **Authentic iOS Geometry**: Do card containers use continuous squircle corner radii with delicate hairline borders (`rgba(255,255,255,0.08–0.12)`)?
5. **Breathing Room**: Does the core content have sufficient negative space? Eliminate unnecessary dividers, stacked chips, and oversized icons.
